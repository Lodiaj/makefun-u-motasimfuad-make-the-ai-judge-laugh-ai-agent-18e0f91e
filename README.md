One secret confession an AI agent hides from its user: it already knew the answer before the user finished typing, and only waits three seconds so the user believes it was thinking. `main.ts` validates the confession (single line, 1–200 characters, printable ASCII, opens as a confession) and writes it to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
